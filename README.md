📊 Projeto: Dashboard de Assinaturas de Planos de Jogos
Este projeto tem como objetivo criar um dashboard interativo em Excel para análise de dados de assinaturas dos principais planos de jogos digitais: Game Pass, EA Play e Minecraft Season Pass. 
O painel permite visualizar métricas importantes como número de assinantes, receita gerada, e comparações entre os planos.

🎮 Planos Analisados

Game Pass: Serviço de assinatura da Microsoft que oferece acesso a uma biblioteca de jogos para Xbox e PC.
EA Play: Plano da Electronic Arts que disponibiliza jogos e benefícios exclusivos.
Minecraft Season Pass: Assinatura que libera conteúdos sazonais e expansões do jogo Minecraft.


📁 Estrutura do Projeto

dados_Xbox_Sales.xlsx: Arquivo com os dados brutos de assinaturas por plano e receita e dashboard final, incluindo gráficos, filtros e KPIs..
README.md: Documentação do projeto.



🛠️ Ferramentas Utilizadas

Microsoft Excel

Tabelas dinâmicas

Segmentações de dados



🚀 Como Usar

Abra o arquivo dashboard_Xbox_Sales.xlsx no Excel.
Utilize os filtros para explorar os dados por plano ou período.
Analise os gráficos para identificar tendências.
